# 操作系统课程实验仓库

本仓库用于提交操作系统课程的实验源代码与实验报告。

## 仓库结构

- **一个分支对应一次实验**，分支以 `labx` 命名（例如 `lab1`、`lab2`）。
- 每个实验分支的根目录下包含两个文件夹：
  - `code/`：对应实验实现后的代码
  - `report/`：包含以下内容
    - `report.md`：实验报告
    - `prompt.md`：本实验所有提示词的汇总
    - `images/`：实验报告中提及的测试结果截图

## 分支说明

| 分支 | 内容 |
| --- | --- |
| `main` | 仓库说明（本文件）与 `.gitignore` |
| `lab1` | 实验一：比麻雀更小的麻雀（最小可执行内核） |
